Install Meeting Saathi

A one-time setup, step by step.

1. Download the extension Download ZIP
2. Extract the ZIPKeep the extracted folder somewhere permanent -- Chrome loads it from that folder every time it starts.
3. Open Chrome extensionsGo to chrome://extensions.
4. Turn on Developer modeUse the toggle in the top-right of that page.
5. Load unpackedClick "Load unpacked" and select the extracted folder.
6. Pin itClick the puzzle-piece icon in Chrome's toolbar and pin Meeting Saathi.
7. Connect your account

Click below once the extension is loaded. This links it to your Meeting Saathi account -- no code to type in.

8. Allow microphone accessChrome will ask for microphone permission the first time you start recording -- allow it.
You are responsible for informing meeting participants and obtaining any consent or permission required by law before recording. See our AI Disclaimer.
