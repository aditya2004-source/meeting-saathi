Setup

Install the extension

A one-time setup. Once connected, Meeting Saathi records from your own browser tab -- no bot joins your call.

Add to Chrome -- it's free

Having trouble with the Chrome Web Store? Download the ZIP and load it manually instead.

1

Add it to Chrome

Click "Add to Chrome" above, then confirm "Add extension" in Chrome's own prompt.

2

Pin it to your toolbar

Click the puzzle-piece icon in Chrome's toolbar and pin Meeting Saathi so it's always one click away.

3

Connect your account

Click below once the extension is installed. This links it to your Meeting Saathi account -- no code to type in.

4

Allow microphone access

Chrome will ask for microphone permission the first time you start recording -- allow it.
